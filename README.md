# Rock, Paper, Scissors

A simple implementation of the classic Rock, Paper, Scissors game. Choose a move, let the computer choose one at random, and see who wins the round.

## How to play

1. Choose **rock**, **paper**, or **scissors**.
2. The computer selects a move.
3. Compare the moves:
   - Rock beats scissors.
   - Scissors beats paper.
   - Paper beats rock.
   - Matching moves result in a draw.

## Example

```text
You chose: rock
Computer chose: scissors
You win!
```

## Rules

| Your move | Wins against |
| --- | --- |
| Rock | Scissors |
| Paper | Rock |
| Scissors | Paper |

## Getting started

Clone or download this project, then run the game using the command appropriate for the language or platform used by the implementation.
